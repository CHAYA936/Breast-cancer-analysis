# 🧬 BREAST CANCER PREDICTION

### Finding Patterns. Building Predictions. Supporting Early Analysis.

Medical datasets contain complex patterns that are difficult to identify by simply looking at individual values.

This project explores how **Machine Learning** can learn patterns from breast cancer data and use them for classification.

---

## 🔬 THE CORE IDEA

> **Can a machine learning model learn meaningful patterns from diagnostic data?**

The project follows a structured ML workflow:

```text id="mlflow1"
DATA
  ↓
CLEANING
  ↓
EXPLORATION
  ↓
PREPROCESSING
  ↓
FEATURES
  ↓
MODEL
  ↓
PREDICTION
```

---

## 🧠 WHAT THE MODEL LEARNS

The dataset contains diagnostic measurements that can be used to identify patterns associated with different classes.

Rather than manually defining every rule, the model learns relationships from the available training data.

---

## ⚙️ MACHINE LEARNING PIPELINE

### 01 — Data Preparation

Preparing the dataset for analysis and modelling.

### 02 — Exploratory Analysis

Understanding distributions, relationships, and patterns within the data.

### 03 — Feature Processing

Preparing relevant features for machine learning.

### 04 — Model Training

Training a classification model using the prepared dataset.

### 05 — Evaluation

Checking how effectively the model performs on unseen data.

### 06 — Prediction

Using the trained model to classify new observations.
